# M0 概念：指针与引用

## 1. 指针是什么

指针是一个变量，里面存的是地址。

```cpp
int a = 10;
int* p = &a;    // &a 表示取 a 的地址，p 存这个地址
```

- `p`：指针变量；
- `*p`：顺着 p 里的地址，找到那个 int；
- `*p = 20;`：把 a 改成 20；
- `p` 可以改成指向别的变量；
- `p` 可以是空指针 `nullptr`。

再指向别的变量：

```cpp
int b = 99;
p = &b;         // p 现在指向 b
```

## 2. 引用是什么

引用是给已有变量起一个别名。

```cpp
int a = 10;
int& r = a;     // r 是 a 的另一个名字
```

- `r` 必须创建时绑定；
- 绑定后不能改绑到别的变量；
- 不能是空；
- 用 `r` 时不需要写 `*`；
- `r = 20;` 等价于 `a = 20;`。

## 3. 对照表

| 对比项 | 指针 | 引用 |
| --- | --- | --- |
| 存什么 | 地址 | 已有变量的别名 |
| 能不能为空 | 可以，nullptr | 不可以 |
| 能不能改指向 | 可以 | 不可以 |
| 怎么访问原值 | `*p` | 直接写名字 |
| 是否必须初始化 | 建议初始化 | 必须初始化 |

## 4. 在这个项目中怎么用

- `const Tensor& other`：传参时不复制整个矩阵。
- `float& at(...)`：返回可以修改的格子。
- `const float& at(...) const`：只读格子，不能通过返回值修改。
