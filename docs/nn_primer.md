# 零基础神经网络推理最小知识

## 1.  Tensor 是什么

Tensor 就是多维数组。

- 一维 Tensor：一串数字，例如 [1, 2, 3]；
- 二维 Tensor：矩阵，例如 [[1, 2], [3, 4]]。

在我们项目里，Tensor 的主要工作是：

- 保存 shape；
- 保存 data；
- 支持按下标访问；
- 支持矩阵运算。

## 2. 线性层是什么

一个神经元做加权求和：

y = w1*x1 + w2*x2 + ... + b

写成矩阵就是：

y = Wx + b

其中：

- x 是输入；
- W 是权重；
- b 是偏置；
- y 是输出。

推理时，W 和 b 是已知的，不需要训练。

## 3. ReLU 是什么

ReLU(x) = max(0, x)

- 输入 -2，输出 0；
- 输入 3.5，输出 3.5。

它的作用：给网络加入非线性。

## 4. Softmax 是什么

把一组分数变成概率。

例如：

输入 [2, 1]  
输出 [0.73, 0.27]

## 5. MLP 前向是什么

MLP 就是一串操作：

Linear -> ReLU -> Linear -> ReLU -> Linear -> Softmax

推理就是拿着已知权重，从输入算到输出。

## 6. 训练是什么

训练就是：

从数据中自动找到合适的 W 和 b。

训练和推理是两件事。  
当前阶段先只做推理。

## 7. 现在不需要学什么

- 反向传播推导；
- 梯度下降；
- 损失函数；
- 优化器；
- CNN / RNN / Transformer；
- CUDA 和分布式训练。

这些以后做到对应阶段再学。

# 第二阶段（线性层 / ReLU / Softmax / MLP）需要的知识

下面这些是阶段 0 做完之后、写阶段 1 之前要先想清楚的东西。

## 8. 形状（shape）怎么推 —— 最实用的一条

写推理代码，绝大多数 bug 都是 shape 对不上。先把规则背下来。

矩阵乘法：

| 操作 | 输入 | 输出 |
| --- | --- | --- |
| `matmul` | (M, K) × (K, N) | (M, N) |

一句话记法：**中间那个维度必须相等，并且会被消掉。**

- `(2,3) × (3,4)` → 中间都是 3，结果 `(2,4)`；
- `(2,3) × (2,4)` → 中间 3 ≠ 2，直接报错。

其他操作：

| 操作 | 输出形状 |
| --- | --- |
| `add` | 和输入相同（要求两边形状完全一样） |
| `relu` | 和输入相同 |
| `softmax` | 和输入相同 |
| `transpose` | (M, N) → (N, M) |

**为什么要单独讲**：`matmul` 的输入和输出形状不一样，
这是它和 `add` / `relu` 最本质的区别，也是最容易写混的地方。

## 9. 线性层：W 到底是怎么摆的

书上写 `y = Wx + b`，但真实代码里（PyTorch）权重是按
`(out_features, in_features)` 存的，不是 `(in_features, out_features)`。
所以实际计算是：

    y = x @ W.T + b

假设一次处理 N 条样本：

| 变量 | 形状 |
| --- | --- |
| `x` | `(N, in_features)` |
| `W` | `(out_features, in_features)` |
| `W.T` | `(in_features, out_features)` |
| `y` | `(N, out_features)` |
| `b` | `(out_features,)` |

**手算例子**（1 条样本，in=3，out=2）：

    x = [[1, 2, 3]]              形状 (1, 3)

    W = [[1, 0, 0],              形状 (2, 3)   ← PyTorch 的摆法
         [0, 1, 0]]

    W.T = [[1, 0],               形状 (3, 2)
           [0, 1],
           [0, 0]]

    b = [0.5, -0.5]              形状 (2,)

    x @ W.T = [[1*1+2*0+3*0, 1*0+2*1+3*0]]
            = [[1, 2]]

    y = [[1, 2]] + [0.5, -0.5] = [[1.5, 1.5]]

所以第 0 个输出是 1.5，第 1 个输出也是 1.5。

**这就是为什么下一步要先写 `transpose()`**：不转置就没法直接用
PyTorch 导出的权重。另一个选择是加载时就把 W 转好再存。

## 10. 偏置 b 和「广播」

`y` 是 `(N, out)`，`b` 是 `(out,)`，形状不同，不能直接相加。
需要把 `b` 沿行方向**复制 N 份**，这叫广播（broadcasting）：

    y     = [[1, 2],        b = [0.5, -0.5]
             [3, 4]]

    b 广播 = [[0.5, -0.5],
             [0.5, -0.5]]

    y + b = [[1.5, 1.5],
             [3.5, 3.5]]

我们的 Tensor 现在**没有**广播功能。先别急着做通用广播，两个简单办法：

1. 在 `linear()` 里手写循环，加 b 时用 `b.at(0, c)`（把 b 当成 1×out 用）；
2. 把 b 提前铺成 `(N, out)`（浪费内存，但最省事）。

等以后真要做通用算子框架了，再实现完整的广播规则。

## 11. Softmax 的数值稳定性（很重要，不是优化）

公式：

    softmax(x)_i = exp(x_i) / Σ_j exp(x_j)

**问题**：`exp` 长得太快。`exp(100)` 已经是 2.7e43，
`exp(1000)` 直接变成 `inf`，于是 `inf / inf = nan`，整个输出就废了。

**技巧**：分子分母同时乘 `exp(-max(x))`，结果完全不变：

    softmax(x) = softmax(x - max(x))

**手算例子**，输入 `[2, 1]`：

- 减最大值 2 → `[0, -1]`
- 取 exp → `[1, 0.3679]`
- 求和 → `1.3679`
- 相除 → `[0.731, 0.269]`

和直接算 `[exp(2), exp(1)] = [7.389, 2.718]` 再除以 `10.107` 的结果一致。

**结论：`x - max(x)` 这一步是必须写的，不是可选优化。**
写完记得拿大数测一下（比如输入 `[1000, 1001]`），不写这步就会拿到 `nan`。

## 12. MLP 前向：完整走一遍

一个两层 MLP（3 输入 → 4 隐藏 → 2 输出）：

    输入 x (N, 3)
      → Linear1: W1 (4, 3), b1 (4,)     → (N, 4)
      → ReLU                            → (N, 4)
      → Linear2: W2 (2, 4), b2 (2,)     → (N, 2)
      → Softmax                         → (N, 2)  概率

每步的形状：

| 步骤 | 形状 |
| --- | --- |
| 输入 | (N, 3) |
| `x @ W1.T` | (N, 4) |
| `+ b1` | (N, 4) |
| ReLU | (N, 4) |
| `@ W2.T` | (N, 2) |
| `+ b2` | (N, 2) |
| Softmax | (N, 2)，每行两列加起来等于 1 |

**写法建议**：每一步单独写成函数并单独测试，
不要一上来就串成一大坨。串起来之后，拿一个固定输入手工算一遍全程，
再和程序结果对比。

## 13. 怎么确认自己算对了

这个项目的原则是「每个函数都要能手算验证」。三种手段，由易到难：

1. **小整数手算**：用 1、2、3 这种能整除的数，自己在纸上算一遍，写进测试。
2. **对拍 PyTorch**：同样的权重和输入，在 Python 里跑一遍，
   把结果和 C++ 的输出逐个数对比。这是阶段 3 的核心方法。
3. **性质测试**（不需要手算，但能抓住很多边界 bug）：
   - `A @ I == A`（单位矩阵）
   - `(A @ B) @ C == A @ (B @ C)`（结合律）
   - Softmax 每行加起来约等于 1，且每个值都在 [0, 1]
   - ReLU 的输出里没有负数
   - `(A @ B).T == B.T @ A.T`（转置和乘法交换，写了 transpose 之后可测）

## 14. 接下来要写的东西（阶段 1 路线）

按依赖顺序：

1. `Tensor::relu()` —— 逐元素 `max(0, x)`，最简单，先热身；
2. `Tensor::transpose()` —— 线性层要用；
3. `Tensor::softmax()` —— 记得减最大值；
4. `linear(x, W, b)` —— matmul + 广播加 b 串起来；
5. 手写一组权重，手工算一遍 MLP 前向，和程序对比；
6. 可选：写个从文件读权重的小工具，为阶段 3 铺路。

每写完一个就：加测试 → 跑 `build.bat test` → 在 `logs/log.md` 记一行。

# 动机：为什么 add / matmul / relu 就是神经网络

写 `add` / `matmul` / `relu` 的时候很容易犯嘀咕：「这些不就是普通的矩阵运算吗，
跟神经网络有什么关系？」这一节专门回答这个。

**一句话：神经网络的前向推理，就是把这三个函数按顺序调用而已，没有别的东西。**

## 15. 一个神经元在算什么

一个神经元做的事：

    y = w1*x1 + w2*x2 + w3*x3 + b

拆开看就是三件事：

- `w1*x1 + w2*x2 + w3*x3` —— **点积**，也叫加权求和；
- `+ b` —— 加偏置；
- 外面再套一个非线性 —— **ReLU**。

## 16. matmul 就是把很多个点积一次算完

一个线性层：3 个输入 → 2 个输出（也就是 2 个神经元）。

    x = [[1, 2, 3]]        1 条样本，3 个特征

    W = [[1, 0, 0],        第 0 个神经元的 3 个权重
         [0, 1, 0]]        第 1 个神经元的 3 个权重

    b = [0.5, -0.5]

`x.matmul(W.T)` 得到 `[[1, 2]]`，其中：

- 结果里第 0 个数 `1` = `1*1 + 2*0 + 3*0` → **第 0 个神经元的加权求和**
- 结果里第 1 个数 `2` = `1*0 + 2*1 + 3*0` → **第 1 个神经元的加权求和**

再加 `b` 得到 `[[1.5, 1.5]]` —— 这就是你写的 `add`。
再过 ReLU 还是 `[[1.5, 1.5]]` —— 这就是你写的 `relu`。

**「线性层 + 激活」就是这么来的，一个字符都没多。**

## 17. 所以对应关系是

| 你写的函数 | 它在神经网络里扮演什么 |
| --- | --- |
| `matmul` | 一大堆神经元同时做加权求和。**网络几乎所有计算量都在这** |
| `add` | 加偏置 `b` |
| `relu` | 非线性激活 |
| `softmax`（下一步） | 把分数变成概率 |

## 18. 为什么必须有 ReLU（这条最容易被忽略）

如果网络里只有 `matmul` 和 `add`，那么堆多少层都等于**一层**：

    W2 * (W1 * x + b1) + b2
      = (W2 * W1) * x + (W2 * b1 + b2)
      = W' * x + b'

乘开之后仍然是「一个矩阵乘法 + 一个偏置」。
**没有 ReLU，100 层和 1 层的表达能力完全一样。**

ReLU 的作用就是打破这个「可以合并」的性质，
让每一层都真的增加表达能力。这也是为什么它叫「非线性」。

## 19. 整个 MLP 前向长什么样

    x (N,3)
      → matmul + add   → (N,4)      线性层 1
      → relu           → (N,4)
      → matmul + add   → (N,2)      线性层 2
      → softmax        → (N,2)      概率

整个网络就是这几步的重复。
**你写的三个函数，就是它的全部积木。**

## 20. 那为什么还要单独写一个 linear()？

因为 `linear(x, W, b)` 里面**没有新东西**，它只是把两步包起来：

    y = x.matmul(W.T)    然后    y + b（广播）

包起来是为了**好读、好复用、好测试**，不是因为里面有新算法。

## 21. 什么时候这个「意义」会变得特别具体

阶段 3：用 PyTorch 训练一个极小的 MLP → 导出权重 →
用你自己写的这些函数跑推理 → 和 PyTorch 的输出逐个数字对比。

到那时候你会发现：**PyTorch 内部做的也就是这些**，
只不过它用高度优化的 C++ / CUDA 写得极快极稳，并且支持自动求导。

你现在是在手搓一台「小号的、能看懂的 PyTorch」。
