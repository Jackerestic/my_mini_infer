# my_mini_infer 路线图

## 阶段 0：C++ 与 Tensor 基础

- Tensor 的 shape 和 data；
- 构造、析构、拷贝；
- at / fill / print；
- add；
- matmul；
- 单元测试。

验收：能正确计算两个矩阵相乘，并用测试验证。

## 阶段 1：线性层与 MLP 前向

- 线性层：y = Wx + b；
- ReLU：max(0, x)；
- Softmax；
- 把线性层和激活函数串起来；
- 用手工权重验证输出。

验收：同一输入，C++ 手算结果与程序结果一致。
