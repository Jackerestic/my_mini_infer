# M0 概念：栈与堆

> 先理解这一个问题：变量到底放在哪里？
> 不要背定义。先看例子，再自己写一遍。

## 1. 一个程序内存大致分两块

- 栈（stack）：小、快、自动管理。
- 堆（heap）：大、慢、需要手动管理。

可以这样想：

- 栈像书桌桌面：拿东西放东西很快，但桌面很小。
- 堆像仓库：地方很大，但你要自己登记、自己归还。

## 2. 栈变量

例子：

```cpp
int a = 10;
```

这行代码里的 `a` 通常在栈上。

特点：
- 函数结束时，`a` 自动消失；
- 不需要你手动释放；
- 速度快；
- 容量有限。

## 3. 堆变量

例子：

```cpp
int* p = new int(20);
```

这里有两样东西：

- `p` 是一个指针变量，它自己通常在栈上；
- `new int(20)` 在堆上申请了一个 `int`，初值是 20；
- `p` 里存的是堆上那个 `int` 的地址。

读取堆上的值：

```cpp
std::cout << *p << '\n';   // *p 表示顺着地址找到那个值
```

释放堆内存：

```cpp
delete p;
```

如果不写 `delete p;`，这块堆内存就不会自动还回去，这叫内存泄漏。
