## 第一部分：Tensor 是什么

1. `Tensor` 这个类想解决什么问题？

我的回答:面向矩阵这个对象，提供矩阵的数据读写，运算等操作
- 

2. `shape_` 存了什么？为什么用 `std::vector<std::size_t>`？

我的回答：这个矩阵的形状，行数和列数，std::size_t是一个专门用来表示大小或下标的整数类型
- 

3. `data_` 存了什么？它和 `shape_` 是什么关系？

我的回答：将矩阵数据一维展开即得到data_，data_中元素个数等于shape_中的行数x列数
- 

4. 一个 3x4 的 Tensor，`size()` 应该是多少？`data_` 里有多少个数？

我的回答：12，12个数
- 

5. 为什么要写 `Tensor(std::size_t rows, std::size_t cols, float value = 0.0f)`？三个参数分别是什么？

我的回答：根据提供的数据构造矩阵，rows是行数，cols是列数，value是矩阵中每个数的值，默认为0.0f

## 第三部分：C++ 概念

1. 一个 .cpp 文件到 .exe，经过哪四步？每一步大概做什么？

我的回答：
- 预处理，编译，汇编，链接。
预处理将头文件展开，将宏展开，去掉注释，生成.i文件
编译将c++语言编译为汇编语言，生成.s文件
汇编将汇编语言转为机器代码，生成.o文件
链接将库函数与.o文件链接起来，生成.exe可执行文件

2. 栈和堆的区别是什么？各举一个我写过的例子。

我的回答：
- 栈是计算机中用来分配局部变量的，在生命周期结束后会自动释放
如int a=10;
堆是程序员手动申请用以管理动态内存，需要手动释放
如int* p=new int(10);
若不手动释放会导致内存泄漏

3. 指针和引用的区别是什么？各写一行代码。

我的回答：
- 指针存储的是一个变量的地址int a=10;int b=99;;int* p=&a;但指针也可以通过解引用来修改变量的值*p=20;
指针与引用的区别在于指针可以指向别的变量p=&b;，而引用在创建时就必须与一个已存在的对象绑定在一起不能修改。比如int& r=a;r=b;就相当于把b的值赋给a，引用只是该变量的一个别名而已。

4. `std::vector` 为什么会扩容？扩容时旧元素怎么办？

我的回答：
- std::vector中一开始分配的内存较小，但随着元素的增多，std::vector会检测size和capacity的大小，若新增元素个数超过capacity的大小，会自动分配一块更大的内存，先将旧内存的元素数据复制或移动到新内存，再将旧内存释放掉，接着加入新元素，增大size和capacity

5. 值传递、引用传递、移动语义的区别？移动为什么能省一次拷贝？

我的回答：
- 在值传递中并不会将原有变量传过去，而是只传这个变量的值。相当于把这个变量的值复制一份发过去。所以不能对原变量造成影响
而引用传递则相当于传原变量。我们前面提到引用只是原变量的一个别名，所以引用传递不用消耗额外的内存，不加const也可以对原变量进行值的修改
在项目中常写const Tensor&是因为Tensor内存可能很大，复制代价很高，所以采用引用传递，但很多情况下要保证Tensor不被修改，所以在前面加const。这样既可以省内存，也起到了保护的作用。

- 移动语义是指在基于一个旧对象构造一个新对象时，知道旧对象后续不再使用，直接将其数据搬给新对象，避免拷贝构造中逐一复制的开销以及指针重叠的问题。
移动构造时直接将原对象的数据拿给新对象，无需复制。拷贝构造相当于搬家时买一套一模一样的新家具，再将原家具丢弃。而移动构造则是直接把旧家具搬到新房子
std::move本身并没有搬东西，它只是将原对象变为一个右值，真正搬东西的是vector中的移动构造函数

CMake 是一个构建系统生成器。它读取 CMakeLists.txt，生成 Ninja 或 Makefile 需要的构建文件，并描述要编译哪些源文件、链接哪些库、头文件在哪里。Ninja 负责按构建规则调度并执行构建。真正编译和链接的是 g++。CTest 负责运行 add_test 注册的测试。

-S 是源代码目录。-B 是构建目录。-G 是生成器，例如 Ninja 或 MinGW Makefiles。

```powershell
cmake -S . -B build -G Ninja                    # 配置
cmake --build build                             # 构建
ctest --test-dir build --output-on-failure      # 测试
```
